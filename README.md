# gues-.c

مجموعة برامج بسيطة مكتوبة بلغة C للتدريب على أساسيات البرمجة.

## البرنامج الرئيسي

`gues.c` هي لعبة تخمين رقم عشوائي من 1 إلى 20. يطلب البرنامج اسم المستخدم، ثم يعطيه إرشادات إذا كان التخمين أعلى أو أقل من الرقم الصحيح.

## الملفات

- `gues.c`: لعبة تخمين الرقم.
- `expense.c`: برنامج تسجيل المصروفات.
- `app.c`: تطبيق تدريبي بسيط.
- `avg.c`: حساب المتوسط.
- `char.c`: تدريب على التعامل مع الحروف.

## التشغيل

يتطلب المشروع مكتبة CS50. لتشغيل لعبة التخمين:

```bash
clang gues.c -lcs50 -o gues
./gues
```
